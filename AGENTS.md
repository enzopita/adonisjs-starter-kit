# Agent notes

- **Before writing code**: find the closest existing example and mirror its shape. Keep the diff to what the task needs; no drive-by renames or refactors.
- **Comments**: only for what the code can't say: why it's done this way, a non-obvious constraint, a link to an issue. Never restate what the names and the body already show; when in doubt, leave it out.
- **Done**: `pnpm typecheck && pnpm lint` pass, plus the narrowest relevant test. If a command can't run (missing infra, no network), report it with its output instead of claiming completion.
- **Backend architecture**: before creating or moving anything under `apps/backend/app/` (controller, action, query, model, transformer, validator, module), read `docs/architecture.md`. Starting a new module or feature: follow its step-by-step section in order. Dependencies between modules are declared in `apps/backend/modules.json` and enforced by the lint.
- **Frontend architecture**: before creating or moving anything under `apps/frontend/src/`, read `docs/frontend.md`. Feature dependencies are declared in `apps/frontend/features.json` and enforced by the lint.
- **Controller responses**: every controller action validates input with `request.validateUsing()` and returns `serialize(...)` (a transformer for models, a plain object otherwise). The frontend's Tuyau types are inferred from that return: a model or bare object leaves them empty.
- **Tests**: before writing, extending, or reviewing any test (unit, functional, e2e), read `docs/testing.md`: one owner layer per behavior, no duplicate coverage.
- **Library docs**: for any AdonisJS, Lucid or VineJS question, read these before guessing or searching the web. If missing or empty, run `pnpm docs:pull` (also updates them). They're gitignored, so root-level Grep/Glob skip them: pass the path explicitly. Read-only: never edit or import from them.
  - AdonisJS v7: `repos/adonisjs-docs/content` (`start/`, `guides/`, `reference/`)
  - Lucid (ORM, query builder, migrations, factories): `repos/lucid-docs/docs/AI-REFERENCE-OVERVIEW.md`, then the topic file (`AI-REFERENCE-ORM.md`, `-MIGRATIONS.md`...)
  - VineJS (validation): `repos/vinejs-docs/content/docs` (`guides/`, `types/`, `extend/`)
- **AdonisJS REPL**: to confirm anything that depends on the booted app (config, env, services, models, mail, the container), run it in `node ace repl` from `apps/backend` instead of reasoning about it. Pipe the input to run it non-interactively, one expression per line, chaining with `.then()` since a `const` from one line isn't visible on the next: `printf "await import('@adonisjs/mail/services/main').then((m) => m.default.send(...))\n.exit\n" | node ace repl`. It uses the dev `.env`, so services from `compose.yaml` must be up (`docker compose up -d --wait` from the root).
